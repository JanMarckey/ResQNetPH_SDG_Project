### Installation Requirements
To run this project, install the following:

- C++ Compiler (G++)
- Visual Studio Code
- Git

### Usage Instructions

1. Clone the repository:
```bash
git clone https://github.com/JanMarckey/ResQNetPH_SDG_Project.git
```

2. Open the project folder in VS Code

3. Compile the program:
```bash
g++ main.cpp -o main
```

4. Run the program:
```bash
./main
```
